## 2. Verification Protocol & Anti-Hallucination Safeguards

1. **No Inferred Eligibility**: Every rule in `master.scheme_eligibility_rules` corresponds to an explicit clause in the cited government operational guidelines. No eligibility conditions were invented or assumed.
2. **Strict Currency & Denomination Units**: All funding limits, caps, and project costs are denominated in Indian National Rupees (INR), with percentages explicitly capped between $0.00\%$ and $100.00\%$.
3. **No Synthetic Floating-Point Embeddings**: Vector fields in `master.document_chunks` are stored as `NULL` with `embedding_status = 'pending'`, awaiting computation by a real embedding model (`text-embedding-004`).
4. **Audit Trail Completeness**: Any calculated value in the application layer must reference an audited `calculation_runs` record storing the calculation engine version and the input parameter snapshot.
